## كيف تتعاملون مع هذي الملفات

كل الملفات بصيغة Markdown (.md). تقدرون:

- **عرضها على GitHub:** github.com/hadeelqa/uwkitchen-website/tree/master/handoff
- **تحويلها PDF:** افتحوا الملف في VS Code، اضغطوا Ctrl+Shift+P، اكتبوا "Markdown PDF: Export"
- **طباعتها:** نفس الخطوة، اختاروا Print
- **تعديلها:** أي محرر نصوص (Notepad, Word, VS Code)
