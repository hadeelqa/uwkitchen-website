## 4. Firebase - قاعدة البيانات + admin login

| | |
|---|---|
| **الرابط** | https://console.firebase.google.com/project/uwkitchen-c3279 |
| **اسم المشروع** | uwkitchen-c3279 |
| **المالك الحالي** | hadeelqa (المصممة) |
| **الإيميل المرتبط** | hadeelqaht@gmail.com |
| **الباقة** | Spark (مجاني) |

**ما تسوّيه Firebase:**

1. **Firestore** = قاعدة البيانات (تحفظ نصوص الموقع، التقييمات، طلبات الصيانة)
2. **Authentication** = نظام تسجيل دخول admin
3. **Storage** = حفظ الصور المرفوعة من admin

**الحدود المجانية:**
- Firestore: 50,000 قراءة/يوم، 20,000 كتابة/يوم
- Auth: مستخدمون غير محدود
- Storage: 5GB إجمالي + 1GB تنزيل/يوم

> هذي الحدود سخية جداً. لن تصلوا لها إلا إذا الموقع نما عشرات الأضعاف.

**عند التسليم:** يُضاف إيميل الشركة كـ Owner.

## 🔄 كيفية نقل الحسابات (عند التسليم)

### Netlify
1. افتحوا https://app.netlify.com/teams
2. Settings → Members → Invite member
3. أضيفوا إيميل الشركة كـ Owner
4. بعد التأكيد، حذف الإيميلات السابقة

### Firebase
1. افتحوا Firebase Console → Project settings → Users and permissions
2. Add member → إيميل الشركة → Role: Owner
3. تأكيد

### GitHub
**خياران:**
- **نقل الملكية:** Settings → Transfer ownership → إيميل الشركة
- **إضافة Owner:** Settings → Collaborators → Add → Role: Admin

### Cloudinary
1. Settings → Users → Invite User
2. الدور: Master Admin

## 🛡️ أفضل الممارسات الأمنية

- ✅ استخدموا إيميل خاص بالشركة لكل الحسابات (مثلاً `tech@uwkitchens.com`)
- ✅ فعّلوا Two-Factor Authentication (2FA) على كل الحسابات
- ✅ استخدموا مدير كلمات سر (1Password, LastPass, Bitwarden)
- ❌ لا تشاركوا كلمات السر في WhatsApp/Email عادي
- ❌ لا تستخدموا نفس كلمة السر لخدمتين
